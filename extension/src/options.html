Shizuku 收录 · 设置

先双击 shizuku\bridge\启动中转.bat，窗口开着别关。第一次用前还要双击 登录 Claude.bat 登录一次。

在 console.anthropic.com 创建。只存在这台电脑的扩展存储里，只发给 api.anthropic.com。建议单独建一把 Key，并在控制台设好每月花费上限。

一次开 款

Claude 是一款一款排队处理的（每款约半分钟到一分钟），开再多也不会更快，只是排队更长；一下子开太多页对网站也不礼貌。所以最多 5。

第一次使用

  1. 在 chrome://extensions 里找到本扩展 → 详细信息 → 打开「允许访问文件网址」（Cellar 是本地文件，不开这个扩展进不去）。
  2. 用订阅：双击 登录 Claude.bat，输入 /login 登录 Pro 账号（只做一次）；再双击 启动中转.bat，把显示的口令填到上面。
  3. 打开你的 Cellar（shizuku_cellar_v7.13…html），它会把库存名单同步给扩展。
  4. 去 htreviews.org 正常浏览。右下角会显示「你有 / 库存里没有」；打开烟料页会自动交给 Claude 处理。
  5. 回到 Cellar 的 HTReviews 页，处理好的结果在「待确认」里，确认后挂到对应的料上。
